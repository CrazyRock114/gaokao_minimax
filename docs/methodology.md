# 方法与口径说明

本文档记录从 LaTeX 语料到题库系统的每一步做法、验证方式与已知局限，
以便复核与复现。所有脚本在 `pipeline/`，可重复执行。

---

## 1. 语料结构

上游 `DxAThing/Gaokao-Math-Problems-Compilation` 把真题整理成逐题结构：

```latex
\chapter{2006年北京卷（理）}
\section{单选题}
\begin{problem}
在复平面内，复数 \(\frac{1+\i}{\i}\) 对应的点位于（\quad）
\choices{第一象限}{第二象限}{第三象限}{第四象限}
\begin{answer} D \end{answer}
\begin{solution} 因为 \(\dfrac{1}{\i}=-\i\)，所以 ... \end{solution}
\end{problem}
```

即：**题干 / 选项 / 答案 / 详细解析 / 题图** 五要素齐全，这是本项目能直接产出
「带解答的题库」而不必重新解题的原因。

---

## 2. 解析（`parse_tex.py`）

### 2.1 平衡括号扫描

手写 `find_matching()`，用编译后的 `re` 正则扫描 `{`/`}`（C 速度），
而不是逐字符 Python 循环——后者跑全量语料要几十分钟，改完是 **2 秒**。

### 2.2 处理的三种上游排版差异

1. **答案在 problem 外**（多数）：
   `\end{problem}` → `\begin{answer}` → `\begin{solution}`
2. **答案嵌在 problem 内**（65 个文件，如 `1983/national_science.tex`）：
   `\begin{problem}` → `\choices` → `\begin{answer}` → `\begin{solution}` → `\end{problem}`
   → 由 `pull_blocks()` 先从题-body 里摘出来。
3. **没有 `\section` 的早期卷**（如 `1956/national.tex`，题目直接挂在 `\chapter` 下）：
   若首个 `\section` 之前存在 `\begin{problem}`，补一个隐式 section，
   题型由 `infer_section_type()` 依据 `choices` / `fillinblank` 推断。

### 2.3 完整性校验

`verify_parse.py` 对 775 个源文件逐个比对 `\begin{problem}` 出现次数与入库题数：

```
files with mismatch: 0 / 775
total src=16273 got=16273 missing=0
```

> 踩过的坑：`extract_env()` 最初把 body 切到「下一个 `\begin`」而不是「本个 `\end`」，
> 题目正文会吞掉答案和解析。**计数校验发现不了这类错误**（总数仍然对得上），
> 必须抽查内容才发现。

## 3. 渲染（`latex_render.py`）

把自定义宏映射为 MathJax 可识别的写法，再把文本切分为「中文段落 / 数学片段」，
中文保持 HTML，数学交给 MathJax 的 `\( \)` / `\[ \]`。

主要映射：

| 上游宏 | 处理 |
|---|---|
| `\bs{x}` | `\mathbf{x}` |
| `\i` `\e` `\d` | `\mathrm{i}` / `\mathrm{e}` / `\mathrm{d}` |
| `\R` `\Z` `\N` | `\mathbb{R}` 等 |
| `\fillinblank` | `\underline{\hspace{2.2em}}`，并补 `\(...\)` 以便渲染 |
| `\circled{n}` | ①②③…（≤20）否则 `(n)` |
| `\myarc{x}` | `\overset{\frown}{x}` |
| `\examdisplaycases{a}{b}` | `\[a\begin{cases}b\end{cases}\]` |
| `\examdisplayaligned/cases/array/chain` | 对应的 `aligned/cases/array/align*` |
| `\bitmapfigure{...}` | `<figure><img src=...>` |
| `\FigureLayoutDeclare` / `\FigureTrimDeclare` | 丢弃（纯排版指令） |

### 3.1 搜索用纯文本投影

`tex_to_plain()` 额外把符号翻成中文，让「垂直」能搜到写作 `\perp` 的题：

```
\alpha\perp\beta  →  阿尔法垂直贝塔
\lim_{n\to\infty} →  n趋于无穷
```

> 踩过的坑：符号替换最初没有加词边界，`\le` 命中 `\left` 内部、`\lim` 命中 `\limits` 内部，
> 留下「小于等于ft」「极限its_」这类残片。现在每个裸控制词都补 `(?![a-zA-Z])`。

### 3.2 渲染质量校验

统计**落在数学定界符之外**的裸宏（这才会被 MathJax 漏掉、显示成源码）：

```
problem_html   macros outside math: 0
solution_html  macros outside math: 0
answer_html    macros outside math: 0
```

## 4. 知识点打标（`taxonomy.py` + `enrich.py`）

### 4.1 体系

18 个主题 / 66 个叶子知识点，按《普通高中课程标准（2017 年版 2020 年修订）》组织，
并补充了早期高考特有内容（行列式、正多面体、物理/工程应用）与代数预备知识。

### 4.2 打分

三路证据分别取证后加权合并：

```
score = 1.00 × 命中题干(raw)
      + 0.55 × 命中解析(raw)
      + 0.20 × 命中选项(raw)
raw   = Σ(1 + 0.6 × min(关键词长度, 8))   # 长词组特异性更强
```

- **选项权重最低**：干扰项经常提到别的考点（「轨迹」题的选项里有椭圆/双曲线），
  早期版本因此给大量纯几何题打上解析几何标签。
- **关键词按长度加权**：`单调递增区间`(6字) 得分高于 `动点`(2字)，
  否则泛化概念会盖过真正在考的解法。
- **保留得分 ≥ 最高分 28% 且 ≥ 1.6** 的标签，最多 8 个。
- **时代限定**：`GEO4`/`GEO5` 这类「早期内容」标签只在 `year ≤ 1985` 生效。

> 踩过的坑（两个都曾让统计严重失真，且都通过了当时的检查）：
> ① `\in` 未加词边界 → 命中 `\infty`/`\int`；
> ② 关键词 `\\{x\s*\\|` 末尾的 `|` 是**正则的择一运算符**，整条规则退化成「匹配空串」，
>    于是 9,213 道题（57%）被打上「集合」，而实际只有约 500 道。
>    现在打标时会跳过零长度匹配，并对裸控制词自动补边界。

### 4.3 质量

- 覆盖率：**99.0%** 有标签，157 题（0.96%）未命中；每题平均 3.16 个标签
- 随机抽样 40 题人工裁决（seed=20260930，`pipeline/tag_quality.py` 可复现）：
  **严格正确 25/40 (62%)，可接受 30/40 (75%)，明显错误 10/40**。典型失效模式：
  因式分解→椭圆、线性规划→不等式性质、正方体异面直线→排列组合、
  切线倾斜角→圆的性质。这类「多考点题里主标签选错」是规则打标的固有误差。
- `pipeline/audit_tags.py N` 可复现抽样

## 5. 难度

1–5 启发式，仅供相对比较与组卷配平，**不是官方难度系数**：

| 因素 | 影响 |
|---|---|
| 题型基线 | 单选 1 / 填空 2 / 解答 3 |
| 解析长度 | >900 字 +2；400–900 +1.5；150–400 +0.5 |
| 小问数（`\item`） | ≥3 +1；=2 +0.5 |
| 含证明（求证/证明/试证） | +0.5 |
| 开放性（是否存在/讨论/任意…） | +0.5 |
| 含题图 | +0.25 |
| 知识点个数 ≥4 | +0.5 |

最终裁剪到 [1,5]。

## 6. 站点构建（`build_site.py`）

按「最小原则」只搬运**真正被引用**的题图：上游 4,341 张 PNG 中，实际被 16,273 道题引用 **2,761 个**
（2,638 张 PNG 位图 + 123 个 `img_repaint/*.tex` TikZ 矢量源码），全部复制，零缺失。

TikZ 源码无法作为 `<img>` 渲染，这 123 个在页面上以「矢量题图源码 · 点击查看」的链接呈现，
而不是输出一个必然裂开的图片标签。

分片策略：

- `data/index.json`：16,273 条轻量记录（约 400 B/条），用于筛选、计数与结果列表
- `data/p/<year>.json`：该年完整记录（HTML / 答案 / 解析 / 图），展开题目或组卷时才按需加载
- `data/manifest.json`：facet 计数、知识点树、知识点×年份交叉表

## 6.5 复审中修掉的「会静默失真」的问题

按严重性排序，都是**计数校验发现不了、只有逐条核对内容才能发现**的：

| 问题 | 影响 | 修法 |
|---|---|---|
| `extract_env` 切到下一个 `\begin` 而非本个 `\end` | 每题正文吞掉答案与解析 | 切到 `e`；加入内容抽查 |
| 无 `\section` 的早期卷（1956 等） | 整卷 0 题入库 | 补隐式 section + 题型推断 |
| `\choices` 是 `\choicesfive` 的前缀 | 84 道五选项题**丢掉全部选项** | 改用带 `\b` / `(?!five)` 的正则 |
| `clean_tex` 把 `\%` 当注释 | **136 道题被截断**（33 题干/27 解析/3 答案） | `(?<!\\)%` |
| 标签阈值用绝对下限 1.6 | 命中结果被**整条丢弃**（含主标签） | 下限改为相对值，并强制保留主标签 |
| `build_site` 章节去重时泄漏循环变量 | **66 个知识点计数全错**（SEQ1 差 5.3 倍） | 修正作用域 + 加构建期不变量断言 |
| `MULTI` 捕获第一个省份后丢弃 | 24 道联考卷地区字段与显示名不符 | 拼接 r1+r2 |
| `season` 提取后未使用 | `（春文）` 型春季卷 variant 判错 | 用捕获组判 variant |
| 派生答案未刷新 `answer_html` | 记录自相矛盾（tex=BC / html=空） | 重新渲染并回写 |
| 19 条依赖 LaTeX 命令的关键词 | 集合/极限/向量**实际从未被识别** | 改为匹配 `SYMBOL_CN` 产出的中文 token |
| 圆锥曲线未互斥 | 双曲线/抛物线被判成椭圆 | 互斥剪枝 |

配套加了两个可执行校验，避免同类问题复发：
`selftest_parse.py`（30 项单测）与 `acceptance.py`（26 项全库验收，均已通过）。

## 7. 已知局限

1. 标签基于正则与关键词统计，**非语义模型**。抽样 40 题人工裁决：主标签严格正确 62%、可接受 75%。这是本系统最主要的质量上限。
2. 难度与标签均无人工校核。
3. 「题量」是**本语料库收录数量**，不等于当年真实考卷题量或考生规模。
4. 1966–1976 年无高考，语料中无对应数据，图表留空。
5. 分析基于整理后的 LaTeX（DxAThing），与原始扫描 PDF（deekur）在极少数题目上可能存在转写差异。
6. 约 0.05%（8/16,273）的记录仍有个别排版标签残留，不影响阅读。
7. 123 道题的题图只有 TikZ 源码、无位图，页面以链接形式给出源码，需自行用 LaTeX 编译查看。
