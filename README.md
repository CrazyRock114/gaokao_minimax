# 高考数学真题题库系统（1952–2026）

把两个 GitHub 上的高考数学真题仓库，转成一套**可读、可检索、可拆分、可改编、可组卷**的结构化图文题库，
并附一份多维度数据分析。

## 数据来源

| 仓库 | 内容 | 许可 |
|---|---|---|
| [deekur/gaokaomath](https://github.com/deekur/gaokaomath) | 777 份原始扫描卷 PDF（711 MB），1952–2026 | CC BY 4.0 |
| [DxAThing/Gaokao-Math-Problems-Compilation](https://github.com/DxAThing/Gaokao-Math-Problems-Compilation) | 在前者基础上整理的 LaTeX 题库：1166 个 `.tex`（逐题含**答案与详细解析**）+ 4341 张题图 | CC BY-SA 4.0 |

本项目**只用**了这两个仓库的公开内容，未修改上游仓库。派生内容遵循 CC BY-SA 4.0（署名 + 相同方式共享）。

> 注：任务描述里写的是「1952–2006」，但两个仓库实际收录到 **2026** 年。本系统按**全量 1952–2026** 建库，
> 1952–2006 部分自然包含在内。

### 快速开始

**只想看题库**（本仓库已包含构建好的站点）：

```bash
cd site && python3 -m http.server 8817
# 打开 http://localhost:8817
```

必须用 HTTP 打开（前端要 `fetch` JSON，`file://` 会被 CORS 拦）。

**想从零重建**（上游语料不在本仓库，需先拉取约 1 GB）：

```bash
bash scripts/fetch_sources.sh     # 拉取两个上游仓库
python3 pipeline/parse_tex.py     # 解析
python3 pipeline/enrich.py       # 渲染 + 打标签 + 难度
python3 pipeline/build_site.py   # 生成站点
python3 pipeline/make_report.py  # 生成报告
```

### 本仓库包含 / 不包含什么

| | 内容 | 理由 |
|---|---|---|
| ✅ 含 | `site/` 完整站点（含 113 MB 题图）、`pipeline/` 全部脚本、`docs/` | clone 后直接可用 |
| ❌ 不含 | `vendor_deekur/`（711 MB）、`vendor_dxathing/`（306 MB） | 上游第三方仓库，体积过大；用 `scripts/fetch_sources.sh` 拉取 |
| ❌ 不含 | `data/*.jsonl`（106 MB） | 可由 `pipeline/` 在约 90 秒内重新生成 |

两处省略的内容都是**确定性可复现的**：同样的上游输入，管线总是产出同样的文件。

| 浏览器 JS 错误 / 4xx / 5xx | **0 / 0 / 0** |
| 知识点覆盖率（至少 1 个标签） | **99.0%**（157 题无标签） |
| 知识点**主标签**人工裁决准确率 | **严格正确 25/40 (62%)，可接受 30/40 (75%)** |

> **关于「100% 准确」**：结构、渲染、交互、计数、图完整性这几项我做到了可验证的 100%。
> 但**知识点的语义判断做不到 100%** —— 打标器是规则式（66 个知识点 × 关键词 + 加权打分），
> 不是语义模型。抽样人工裁决 40 题，11 题主标签明显不当（例如「因式分解」被判成椭圆、
> 「线性规划」被判成不等式性质、「正方体异面直线」被判成排列组合）。
> 这是规则方法的固有边界，靠继续加宽泛关键词只会引入更多误报，所以我停在这里并把数字写清楚。
> 想要更高准确率，需要换成模型语义打标，那是另一条路线。

复现裁决样本：`python3 pipeline/tag_quality.py 40`

## 题库功能

- **浏览**：按年份区间/年代、地区、科类、题型、难度、知识点（主题→知识点两级）、是否含图、是否含解析多维筛选，facet 实时计数
- **检索**：全文搜索题干 + 选项 + 解析（`index.json` 内 `pl` 字段为完整纯文本投影，约 6.1 M 字符）；`\perp` 这类 LaTeX 符号会映射成「垂直」再检索
- **展开**：单题完整渲染（MathJax 公式 + 选项 + 答案 + 解析 + 题图）
- **组卷**：把题加入试卷（localStorage 持久化），按年份自动分节，可切换「只含题目 / 含答案」
- **导出**：打印/导出 PDF（A4 排版）、导出 JSON（含答案解析与图路径）、导出 LaTeX（`ctex` 可编译）
- **改编**：任意题可单独导出 JSON，字段含 `problem_latex / answer_latex / solution_latex / figures`，可直接再加工

```bash

```

## 方法与局限

详见 [`docs/methodology.md`](docs/methodology.md)。要点：

- **解析**：手写平衡括号扫描器，处理了上游两种排版（`\end{problem}` 在答案外 / 答案嵌在 problem 内）
  和无 `\section` 的早期卷。`verify_parse.py` 逐文件比对源与产出。
- **渲染**：把上游自定义宏（`\bs` `\i` `\R` `\fillinblank` `\examdisplaycases` …）映射为 MathJax 可识别的写法。
- **打标**：规则式标签器，按关键词**长度加权**（`单调递增区间` 权重高于 `动点`），
  题干/选项/解析分三路取证（选项权重最低，因为干扰项常提到别的考点）。
- **难度**：1–5 启发式（题型基线 + 解析长度 + 小问数 + 证明/开放性 + 知识点个数），**非官方难度系数**。

**局限**（报告里也写明了）：

- 标签是规则统计，**不是模型语义理解**；2.5%（399 题）未命中任何知识点。
- 难度与标签均未经人工校核。
- 「题量」指本语料库收录数量，不等于当年真实考卷题量。
- 少数早年题存在「理科题命中理科专属知识点」之外的文理越界标记，已作为质量信号保留而非丢弃。
